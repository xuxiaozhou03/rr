# P2-02 记录核心交互流程

> 执行边界：只执行本任务；不要读取整份清单，不要顺手执行下一任务。  
> 会话模式：新线程 / 单任务 / 可验收产物。  
> 输出上限：聊天总结不超过 30 行；命令输出只保留命中行或前 120 行。  
> 结束条件：本任务验收项全部满足，并写出 handoff 文件。

## 输入

- 本任务卡。
- 只按下方“操作”读取实际需要的最小文件。
- 禁止默认加载整份 `REA_COMPETITOR_REVERSE_ANALYSIS_CHECKLIST.md`。

## 任务正文

- 操作：对每个流程执行“触发前 → 操作 → 触发后”。
- 必测流程：
  - 首次进入 `#/3d`
  - 模型加载完成
  - 旋转、平移、缩放
  - 选择对象/图层
  - 切换模型
  - 切换材质、灯光、动画
  - 切换预览参数
  - 刷新与返回
  - 异常与重试
- 产物：
  - `evidence/03-ux/flows/flow-*.md`
  - `evidence/03-ux/screenshots/*`
- 验收：
  - [ ] 每个流程包含前置条件、步骤、预期、实际、证据。
  - [ ] 每个 UI 变化都有对应状态或网络请求解释。
  - [ ] 鼠标、键盘、触控差异已记录。

## 收尾要求

- 将完整证据写入任务正文指定的文件，不把大段原始输出粘贴到聊天。
- 创建 `handoff/P2-02.md`，仅包含：状态、产物路径、结论、阻塞、下一任务建议。
- 未满足验收时标记 `blocked`，不要继续下一任务。
