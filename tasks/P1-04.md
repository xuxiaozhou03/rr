> 执行边界：只执行本任务；不要读取整份清单，不要顺手执行下一任务。  
> 会话模式：新线程 / 单任务 / 可验收产物。  
> 输出上限：聊天总结不超过 30 行；命令输出只保留命中行或前 120 行。  
> 结束条件：本任务验收项全部满足，并写出 handoff 文件。

## 输入

- 本任务卡。
- 只按下方“操作”读取实际需要的最小文件。
- 禁止默认加载整份 `REA_COMPETITOR_REVERSE_ANALYSIS_CHECKLIST.md`。

## 任务正文

- 操作：逐项执行“刷新、进入 3D、旋转、缩放、切换模型、切换材质、退出”。
- 每个动作记录：
  - 时间戳。
  - 请求方法、URL、状态码、耗时。
  - 请求参数与响应结构摘要。
  - 是否携带鉴权、Cookie、租户或追踪字段。
  - 触发该请求的 UI 动作。
- 产物：
  - `evidence/02-baseline/network/request-log.csv`
  - `evidence/02-baseline/network/websocket-log.md`
  - `evidence/02-baseline/network/request-response-samples.md`
- 验收：
  - [ ] 每个动作都有“操作 → 请求 → UI 变化”的对应关系。
  - [ ] 敏感字段已脱敏。
  - [ ] 明确哪些请求是初始化、轮询、按需加载。
