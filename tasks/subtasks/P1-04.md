# P1-04 网络请求与触发动作（子任务总控）

> 先把动作拆开采集，再汇总“操作 → 请求 → UI 变化”。

## 子任务

| 子任务 | 动作 | 产物 |
|---|---|---|
| P1-04a | 刷新 / 首次初始化 | network-refresh.csv |
| P1-04b | 进入 3D | network-enter-3d.csv |
| P1-04c | 旋转、缩放 | network-camera.csv |
| P1-04d | 切换模型 | network-model-switch.csv |
| P1-04e | 切换材质/预览参数 | network-material-preview.csv |
| P1-04f | 退出 / 返回 | network-exit.csv |
| P1-04g | 汇总请求日志、WebSocket、样本 | request-log.csv + websocket-log.md + request-response-samples.md |

## 执行规则

- 每个子任务只做一种动作，HAR 原始文件保留在磁盘，不进聊天。
- 敏感字段先脱敏再写入任何产物。
- `P1-04g` 只读 `handoff/P1-04*.md` 和 CSV，不重新抓包。
