# P2-02 核心交互流程（子任务总控）

> 本任务不能单线程一次跑完。必须按 `P2-02a` 到 `P2-02i` 逐个子线程执行，最后再用 `P2-02z` 汇总。

## 子任务

| 子任务 | 范围 | 产物 |
|---|---|---|
| P2-02a | 首次进入 `#/3d`、模型加载完成 | flow-first-load.md |
| P2-02b | 旋转、平移、缩放 | flow-camera-controls.md |
| P2-02c | 选择对象/图层 | flow-object-selection.md |
| P2-02d | 切换模型 | flow-model-switch.md |
| P2-02e | 切换材质、灯光、动画 | flow-material-light-animation.md |
| P2-02f | 切换预览参数 | flow-preview-params.md |
| P2-02g | 刷新与返回 | flow-refresh-back.md |
| P2-02h | 异常与重试 | flow-error-retry.md |
| P2-02i | 输入设备差异（鼠标/键盘/触控） | input-device-differences.md |
| P2-02z | 汇总为最终流程图与证据表 | flow-summary.md |

## 执行规则

- 每个子任务一个新线程，只采集一个流程。
- 截图和原始记录写文件，聊天只汇报步骤、实际结果、证据路径。
- `P2-02z` 只读全部 `handoff/P2-02*.md` 和流程产物，不重放操作。
